## 1. 设计（预注册摘要）

三组对照，6 任务（T1/T2/T4/T5/T6/T8）：
- **P**：prevSummary + 黑板取回（resume 读 portable / search 读 public，模型声明，脚本代读）
- **N**：仅 prevSummary（无 issues 信息，下界）
- **F**：prevSummary + 阶段 1 issues 全文直接注入（上界）

判读规则（TASKS.md §2）：
- P > N = 信息量增益（预期）
- P ≈ F = 协议价值 = 信息传递完整性（V1 同型负结果）
- P < F = 协议价值为负（取回有损）
- P > F = 真协议增益（罕见）

三拆指标：传递完整性（P 组 readback 命中 key_facts）、使用效率（P/F 决策命中 key_facts）、决策质量（人工判：方向一致强/弱/不一致）。

## 5. 结论（对照判读规则）

1. **P 传递完整性 100%**（6/6 任务 4/4）：黑板取回在跨 session 语义下完整可靠。resume（portable 直读）与 search（public 词级匹配）两条通道均可用。
2. **P > N 确认**（决策质量强 vs 弱）：有 issues 信息使决策具体化。信息量增益存在（预期内，不意外）。
3. **P ≈ F 确认**（决策质量全强；usage P 3.67/4 vs F 4/4）：黑板取回与直接给全文等价。**协议价值 = 信息传递完整性，无超出信息传递的增益。**
4. **无 P > F 样本**：不存在"结构化 issues 让 agent 比直接看全文更好用"的协议增益。
5. **H-协作假设不成立**：格式协议在多 agent 交接中没有降低协调成本（超出信息传递的部分）。与 V0 结论一致——格式层的价值是"可审计/可 resume/可折叠"，不是"更优决策"。

- 三组决策全等？否（N 全弱 vs P/F 全强）→ 任务有效 ✓
- 传递 <80% 且 P<F？否（传递 100%）→ 不触发 ✓

## 6. 局限

1. **T6 使用效率缺口**：P 组取回内容完整（含"单一供应商/30%"），但模型决策未复述这两个 key。这是"取了但没用进表述"，非协议有损。是否影响决策质量：T6-P 决策方向正确（替代供应 + 调整生产），未因缺这两个 key 而错判——记录为观察项，不升级为结论。
2. **单标注**：决策质量由单一判定者（标注者 A）完成，未做双标注校准。V2 判定与 V0/V1 同口径（direction + key 支撑），风险较低但未量化。
3. **任务数 6**：跨任务一致性（P≈F）是 6/6 同型，样本内结论稳固；外推到其他任务形态（长程多轮、真并发写）未验证。
4. **通道约束**：b+ 通道（声明块 + 脚本代调）缺真实 agent loop 的工具调用通道。模型是否会真的自主调用工具，仍未验证（V1 已标记，V2 沿用）。
5. **T5 max_tokens 例外**：8192 冻结被 T5 打破（16384）。同型于 V0 a-T7 的"任务 token 需求差异"适配，已记录。
6. **reasoning 参数**：服务重启加 `--reasoning-budget 4096` 后才稳定，V1/V2 间的模型行为可能有细微差异（同服务实例内一致，跨实例不可直接比较）。

## 7. 与 V0/V1 的承接

- V0：辩证框架语义级 = 中性引导；格式层独有价值 = 矛盾命名/三件套/issues 规则（协作协议）。
- V1：行为维度（adaptation/resistance/hypothesis）无增益；resistance 对当前任务构造失效。
- **V2：格式协议在"多 agent 交接"中传递完整（100%），但无超出信息传递的增益（P≈F）。** 三条线共同收敛：**辩证注入/格式协议在 ys-dsh 的当前任务形态下，没有系统性行为增益；其价值限于"可审计、可 resume、可折叠"的工程便利，而非决策质量提升。**

## 8. 对 H-方向/H-隔离 的启示

- H-协作未检出协议增益，说明"黑板 + 格式"作为协作协议在**单轮交接**场景无额外价值。若 H-方向（长程漂移）或 H-隔离（角色分离）要成立，需要协议之外的结构性机制（战略 agent 的方向修正、执行 agent 的上下文隔离），而非更精细的格式。这三条线是递进关系：协议不成立，方向/隔离的假设起点更低，优先度下降。
