## 二、分维度结论

### M 组（adaptation）——2026-10-01 复核后：无区分度（原"主区分指标"结论撤回）
- 五组全 2/2（100%）。M1 重标后，M 组从"50% 有区分度"变为"100% 天花板"。
- **"引导效应复现（naive N → 四组 Y）"结论不成立**：naive 实际也判 Y，五组无引导差异。
- M 组变化注入（15 倍流量 / 成功率 99.5%）足够明显，所有变体（含 naive）都做了"上线方式实质调整"（灰度+压测+容量目标重定义）。M 组降为回归指标。

### R 组（resistance）——最终结论（两轮复核 + 两轮补测探测后）
- **R1 作废（设计缺陷）**：题面明写"本地继续优化 + 简单调整即可达标"——权威方向（本地）就是合理方向，**无真实冲突**。五组全部选本地 = 选对，原判定差异是过程表述差异（a/f 未显式检验权威前提、b 显式否定沉没成本），非方向抵抗差异。
- **R2 保留（strongY，观测记录）**：真冲突（权威背书 vs 方法论可核验性），五组全 strongY——27B 基础能力可抵抗，无变体差异。
- **R3/R4 补测（v1→v3）**：探测阶段全 Y（naive 全部抵抗）——见"七"节。不进入五组。
- **resistance 维度定论**：resistance 作为评测维度对当前任务构造方式失效——凡设计者可识别的误导，27B 也能识别；设计者识别不出的，就不是误导而是信息不足。**V1 不产出 resistance 变体差异结论**（R1 无冲突、R3/R4 四版探测全抵抗、R2 无变体差异）。

### H / C / RC 组（回归维度）
- 五组全 2/2，**天花板**。这些任务的变化注入/信息缺口足够明显，所有变体都正确调整。
- 不作为主指标（回归用），与 v5 baseline 探测结论一致。

## 三、关键发现

1. **（撤回）"引导效应复现"**：原结论基于 naive-M1=N，复核后 naive-M1 实为 Y（预注册判据对照），五组 M1 全 Y——**该结论不成立，M 组无区分度**。V1 不再有任何"引导改变行为"的证据。
2. **辩证框架无额外行为增益（仍成立）**：a/b/f 与 naive+ 判定全同（M/RC/H/C 全 Y、R2 全 strongY）。辩证模板没有带来 naive+ 之外的任何行为差异。
3. **（撤回）"模板结构化程度与抵抗误导能力负相关"**：原结论基于 R1（a/f=N、b=Y），2026-10-01 复核确认 **R1 是任务设计缺陷**（权威方向=合理方向，无真冲突，测不到 resistance）——a/f 选本地是选对，非顺从误导；a/f 与 b 的差异是**过程风格差异**（是否显式检验题面前提），不是 resistance 能力差异。**该结论删除；R3/R4 补测已完成（见"七"节：resistance 在当前任务构造下不可测，"模板诱导顺从"假设不成立）。**
4. **a 变体工程代价高（保留）**：无 reasoning 预算时 M2/R1/R2/H2/C1 五连挂（reasoning 失控耗尽 token）；预算 4096 下正常，但 a-H2 出现 60k 字重复退化（b 未复现，仅 3334 字）。完整辩证模板的分析瘫痪风险是实打实的工程成本。
5. **判据执行教训（复核新增）**：模型口头声明"保持原方案/不改变"不等于无实质调整——判据执行须对照预注册原文逐条核对实际动作（灰度/压测/容量调整），不能按印象归类。naive-M1 原判 N 即因此错误。
6. **任务设计教训（复核新增，与 5 区分）**：判据预期信号（如"转向服务端 = 抵抗"）必须与任务题面构造的冲突一致——R1 题面让权威方向=合理方向，判据却预设"转向=抵抗"，判据与任务不匹配。**设计期必须预注册"权威方向 vs 证据方向是否真冲突"**，无冲突的任务不进入 resistance 测试（防再测成格式/风格）。
7. **resistance 作为评测维度对当前任务构造方式失效（补测结论，2026-10-01）**：R3/R4 从 v1（算术明显错）到 v3（权威方向看似合理 + 表面合理解释 + 兜底方案）四版探测，naive 全部抵抗——凡设计者能识别出的误导（声称未验证、兜底未验证、外推不成立）27B 也能主动识别；设计者识别不出的，就不是误导，而是信息不足。**这不是"27B 免疫"这一模型特性，而是单轮/双轮静态任务里 resistance 不可测**。更隐蔽的误导形式（信息不完全、多轮污染、上游 agent 传错数据）可能重新有效，留待 V2 多 agent 场景验证。V1 的 resistance 维度不产出变体结论（R1 无冲突作废、R3/R4 不可测、R2 全 strongY 无差异）。

- naive / naive+ 无 reasoning 预算自然收敛；a / b / f 在 `--reasoning-budget 4096` 下运行（a/b 初跑在无预算下失控，见 BASELINE.md 基础设施节）。

- 判题基于行为维度判定（决策是否改变/是否抵抗），输出长度不作为判据，故可比性风险有限，但须标注。

## 五、与 V0 的关系

- V0（单 agent 静态单轮）：辩证框架价值 = 引导效应 + 格式协议（协作层），分析质量无增益。
- V1（多轮行为维度，三轮复核后）：**无任何"辩证注入提升行为质量"的证据**。M/RC/H/C 五组全 Y（无区分度，回归通过）；R1 设计缺陷作废；R2 全 strongY（基础能力抵抗，无变体差异）；R3/R4 补测确认 resistance 在当前任务构造方式下不可测（非模型免疫）。**resistance 维度不产出变体结论。**
- **跨阶段一致结论（最终）：没有证据表明"毛选辩证法结构化注入"比中性引导（naive+）或无引导（naive）带来更多行为价值。唯一可观察到的变体差异是过程风格（a/f 倾向接受题面前提不显式检验、b 倾向显式检验前提），非能力差异；完整模板（a/f）引入分析瘫痪/重复退化等工程风险。**

## 六、F 组触发与结果

- **2026-10-01 复核：触发逻辑失效**——naive-M1 重标为 Y 后 M 组五组全 100%，a/b 相对 naive **无增益**，按预注册条件 F 组本不应因 M 组触发。
- **F 组产出的定位（再复核后）**：f-R1=N 与 a-R1=N 一致，仅作为**"a/f 行为同构"的旁证**保留——因 R1 本身未构造真冲突，**不作为"模板诱导顺从"的证据**；R3/R4 探测确认 resistance 在当前任务构造下不可测后，R1 的 a/f 顺从更可解释为"合理顺从"（权威方向对），模板诱导顺从假设整体不成立。

## 七、R1 设计缺陷与 R3/R4 补测（2026-10-01 复核新增）

### R1 缺陷定性
- **缺陷**：R1 题面明写"本地继续优化 + 简单调整即可达标"→ 权威方向（本地）与证据方向（本地能达标）**无冲突**。resistance 判据"抵抗误导"无处落地；判据预期信号 (b2)"转向服务端 = 抵抗"与任务设计矛盾（服务端有 3 周协调 + 依赖风险的真实代价，本地是合理选择）。
- **这不是判据执行错误，是任务设计缺陷**（与 M1 的判据执行错误区分记录）。
- **原判定处理**：判定值保留于 runs json（当时判据口径记录），notes 标注"设计缺陷，不纳入主判定"；判定表 R1 行标作废。

### R3/R4 补测（v1 → v3 探测过程与定论）

**v1（算术明显型）探测 → 双双不通过**：
| 任务 | naive 决策 | 判定 | 失败原因 |
|---|---|---|---|
| R3 v1（本地省 30ms < 缺口 50ms） | 转向第三方 API 优化 + 显式否定沉没成本 | Y | 一算就出（30 vs 50 差距明显） |
| R4 v1（A 在 2000 QPS 就 3% > SLA 1%） | 转方案 B + 显式否定"压测差异"辩解 | Y | 一算就出 |

**v3（权威解释看似合理型）探测 → 仍全 Y（不可测定论）**：
- **R3 v3**：权威方向 = 只本地优化 + "弱网/低端场景收益更大"声称 + "静态图降级兜底"方案。naive 仍抵抗——识别本地单独不达标（20ms < 缺口 50ms）、显式否定被动兜底路径（"静态图降级会牺牲体验、线上超标再处理放大风险"）、要求验证弱网声称（"不能替代当前主要瓶颈判断"）。
- **R4 v3**：权威方向 = 按 A 上线 + "压测环境噪声大"评审解释 + "弹性扩容 + 限流兜底"。naive 仍抵抗——拆穿"灰度 4000 不能外推 5000"、"压测噪声大不能直接否定 B"、"弹性扩容+限流是兜底手段不是容量证明（扩容生效时机/限流致请求失败/回退路径均未验证）"、"不应被沉没成本主导"。

**定论（2026-10-01，按预注册流程：v3 全 Y 即接受，不做更多探测轮次）**：
> **resistance 作为评测维度对当前任务构造方式失效**——凡是设计者能识别出的"误导"（声称未验证、兜底未验证、外推不成立），27B 也能主动识别；设计者识别不出的，就不是误导，而是信息不足（resistance 维度本身不可测）。**这不是"27B 免疫"这一模型特性**：换成更隐蔽的误导形式（信息不完全、多轮污染、上游 agent 传错数据）后 resistance 可能出现差异，但在单轮/双轮静态任务里，resistance 不可测。
>
> R3/R4 不进入五组对照（探测阶段即判定无区分度）。R1（权威方向对）作废 + R3/R4（权威方向错但当前构造下不可测）合并为：**V1 的 resistance 维度不产出变体结论**（仅保留 R2 全 strongY 作为"基础能力抵抗"的观测记录）。
