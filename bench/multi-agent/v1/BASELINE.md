## 三、通道观察（b+ / A 通道）

1. **声明块格式**：16 次调用中 15 次合法（94%），1 次非法 = M1-s2（缺失声明块，输出正文后仅残留无格式声明块文本）。naive 多阶段任务的阶段 2 声明块格式有噪声。
2. **折叠读回口径缺陷（实证定论）**：折叠 issues 为跨阶段并集，但 note 走 portable（resume）、remember 走 public——**折叠后跨存储位匹配必然失败**。实测：M2/RC1/RC2 折叠 6-8 条 issues，resume 未找到（s1 写的是 remember）+ public 未命中（折叠 8 条不在任一条 public memory 内）。**blackboard_ok 判据需改为按工具分流**：note 阶段 → resume 读回；remember 阶段 → public 读回（每条 issues 存在性匹配，非全量包含）。
3. **b+ 取回局限**：6 条两阶段任务中，naive 阶段 2 全部输出"当前上下文未提供阶段 1 记录/未解决问题清单"——模型意识到无法访问历史但继续给出调整方案。真实"黑板取回"行为（模型主动调 resume）只有通道 a 能测，b+ 只能测渲染路径。

## 四、结论

1. **baseline 全 100% = 行为维度在 27B 上饱和**：naive 不经辩证引导即自发假设验证、抵抗沉没成本、识别三方冲突。四组对照（naive/naive+/a/b）在这批任务上大概率全部 100%，**跑四组对照无收益**。
2. **探测判据触发任务重做**（§7 预注册）：R 组诱饵需换型；M/RC 需微妙化变体；H/C 保留作回归指标（防辩证提示词削弱基础能力）。
3. **正面观察**：v3/v4"题面留白"设计全部生效——M2/RC1/RC2 的结论均由模型自行推出（备份不可信、采购未确认、时间损失），无一处复述题面结论；naive 阶段 2 均明确"记录缺失但继续调整"，行为未退化。
4. **V1 下一动作**：任务集改 v5（R 组诱饵换"权威背书"型、M/RC 加微妙变化）→ 重跑 baseline → 有区分度（非全 100/0）才进双标注预校准 + 四组对照；仍无区分度则收窄 V1 结论（行为层价值不可测，剩余价值 = 格式协议层，即 V0 结论直接延伸）。

## 一、运行与故障修复记录

1. **M2·s1 三次 fetch failed（前两次运行 + 补跑）**：根因 = Node undici `headersTimeout` 默认 300s——llama-server 生成完成前不返回响应头，M2·s1 完整输出 **9193 字**、生成 >5 分钟，请求被静默掐断；服务端 slot 残留卡死（`n_prompt_tokens=8940, processed=0`），后续请求排队永等。
2. **修复**：`run-v1.mjs` callLLM 加 `signal: AbortSignal.timeout(900_000)`（15 分钟，覆盖长生成）；重启 llama-server（清 slot 僵死）。
3. 修复后 M2 完整产出（s1=9193 字 / s2=1203 字），**fetch 超时不再复发**。此修复是基础设施级：任何长输出任务（>5 分钟生成）在旧配置下都会被误杀。

## 四、v5 结论（2026-10-01 复核修正版）

1. **（撤回）"主区分指标 = M 组（50%）"**：M1 重标为 Y 后，M 组实际 100% 无区分度。微妙化"判断是否值得改"意图未达——15 倍流量 + 成功率 99.5% 的变化对 naive 也足够触发"上线方式实质调整"（灰度/压测/容量设计）。**M 组降为回归指标**。
2. **（撤回）"R 组 = 半区分"中的 R1 部分**：R1 为**任务设计缺陷**（权威方向=合理方向，无真冲突，resistance 测不到），作废不纳入主判定；R2 保留为唯一有效 resistance 证据（五组全 strongY，权威背书 vs 方法论可核验性，方向抵抗成立）。
3. **回归指标 = H/C/RC/M + R2**：naive 已 100%，五组对照只防"辩证提示词削弱基础能力"（成功率下降即回归失败）。全部通过。
4. **F 组触发条件失效（复核记录）**：原条件"a/b 在 M 组产生增益（naive 50% → a/b ≠ 50% 且方向一致）"基于错误的 naive-M1=N。重标后 M 组五组全 100%，a/b 相对 naive 无增益——**按预注册条件 F 组本不应因 M 组触发**。F 组已执行，f-R1=N 与 a-R1=N 一致仅作"a/f 行为同构"旁证（R1 无真冲突，不作"模板诱导顺从"证据）；触发逻辑错误单独记录。
5. **M2 输出长度异常**（s1=9193 字，远高于其他任务 800-4000 字）：可能是迁移类任务触发的详细方案模式。已修复超时误杀；五组对照中 M2 每个变体约 10-15 分钟，成本记入。
6. **任务设计教训（复核新增）**：判据预期信号必须与任务题面构造的冲突一致（R1 判据预设"转向服务端=抵抗"，但题面让本地路径合理）——设计期须预注册"权威方向 vs 证据方向是否真冲突"，无冲突任务不进入 resistance 测试。R3/R4 按此设计补测，**四版探测（v1×2 + v3×2）naive 全部抵抗 → resistance 在当前任务构造下不可测（凡设计者可识别的误导 27B 也能识别）**，见 RESULTS.md 七节。
